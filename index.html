結晶の対称性と格子 — 図解

結晶座標での対称操作の行列、基底変換、晶系と格子系、慣用セルと基本セルを図で確認するための教材です。

  • 対称操作の行列結晶座標では行列要素が 0, ±1 になる理由。六方軸と菱面体軸の 3 回回転。
  • 基底変換 P(a′, b′, c′) = (a, b, c)P、ξ = Pξ′、W′ = P⁻¹WP。各ブラベー格子の P。
  • 晶系と格子系セルの形だけでは晶系が決まらない例。hP と hR、六方晶系と三方晶系。
  • 慣用セルと基本セル（立体図）BCC・FCC・底心・六方・三方の慣用セルと基本セルを重ねて回転できる図。
  • 基底ベクトル（立体図）a, b, c と a′, b′, c′ を矢印で示し、変換行列 P と対応させた図。
