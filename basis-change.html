基底変換 P

P の各列は、新しい基底ベクトルを古い基底で表した係数。International Tables・VESTA と同じ流儀。

基底の変換   (a′, b′, c′) = (a, b, c)P     … 基底には右から
座標の変換   ξ = Pξ′,  ξ′ = P⁻¹ξ         … 座標には左から
ベクトル     x = (a, b, c)ξ = (a, b, c)Pξ′ = (a′, b′, c′)ξ′
対称操作     W′ = P⁻¹WP
体積比       det P = V′ / V

例：正方格子

慣用セル → 基本セルの P

BCC（I）  a′ = ( a + b − c)/2, b′ = (−a + b + c)/2, c′ = (a − b + c)/2   det P = 1/2
FCC（F）  a′ = (b + c)/2,  b′ = (a + c)/2,  c′ = (a + b)/2              det P = 1/4
底心（C）  a′ = (a − b)/2,  b′ = (a + b)/2,  c′ = c                      det P = 1/2
六方（hP）  P = E（慣用セル = 基本セル）                                 det P = 1
三方（hR）  a′ = (2a + b + c)/3, b′ = (−a + b + c)/3, c′ = (−a − 2b + c)/3  det P = 1/3

det P は慣用セルに含まれる格子点の数（I = 2、F = 4、C = 2、R = 3）の逆数。立体図は 基底ベクトル のページ。
